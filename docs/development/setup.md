# Development Setup

Requirements: Node.js 24 and npm.

```bash
git clone https://github.com/originlabsbr/originlabs-landing && cd originlabs-landing
npm ci
npm run dev
```

## Conventions

- Code, comments, technical docs, commits, and PRs in English.
- User-facing copy in English, Brazilian Portuguese, and Spanish, kept in sync.
- Conventional Commits, no AI attribution or co-author footers, no em dashes.
- Static only: no API, router, or runtime configuration.
- Keep the site accessible, concise, and free of invented company claims or contact details.
